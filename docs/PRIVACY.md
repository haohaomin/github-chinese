# 隐私说明

适用于浏览器扩展「GitHub 中文化」（Chrome、Edge、Firefox、Safari）。

## 处理的数据

| 数据         | 内容                                                                                                                                        | 存放位置                                                                                               |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 页面文字     | github.com、gist.github.com、www.githubstatus.com、help.github.com、support.github.com 及启用的企业版站点页面上的界面文字，在本地替换为中文 | 不保存                                                                                                 |
| 设置         | 开关、排除路径、翻译语言、界面语言、外观、加速源分类与加速源、自动加载与新标签页打开的范围、新标签页打开的自定义页面                        | `storage.sync`，可能随浏览器账号同步（Safari 不同步）；界面语言与外观另缓存在扩展页面的 `localStorage` |
| 自定义词库   | 你添加的原文与译文                                                                                                                          | `storage.local`                                                                                        |
| 屏蔽规则     | 你填写的搜索净化规则（所有者、存储库、关键词）                                                                                              | `storage.local`                                                                                        |
| 搜索结果     | github.com 搜索结果页上结果的所有者、名称、标题、描述、主题、标签，在本地与屏蔽规则比对                                                     | 不保存                                                                                                 |
| 页面标记     | 翻译期间 `<html>` 上的 `data-gcn-i-<随机 id>` 属性，页面脚本可读取                                                                          | 不保存，停用时移除                                                                                     |
| 加速的地址   | 开启加速后经加速选项或替换原链接打开、复制的下载链接与克隆地址，经加速源下载的文件夹中的文件地址，加载失败的图片地址                        | 不保存；随请求交给选用的加速源                                                                         |
| 版本检查     | 从发行版安装时：最新发行版的版本号、检查时间                                                                                                | `storage.local`                                                                                        |
| 下一页列表   | 开启「自动加载」后取回的同站下一页，列表项接在当前列表之后                                                                                  | 不保存                                                                                                 |
| 下载次数     | 开启「下载次数」后，页面上发行版附件所属的所有者、存储库、标签，以及 GitHub API 返回的各附件下载次数                                        | 不保存；次数在页面内与扩展后台各缓存 10 分钟                                                           |
| 个人访问令牌 | 在设置页「下载次数设置」中填写的 GitHub 个人访问令牌，以及用它查到的剩余额度                                                                | `storage.local`，不同步；清除或卸载扩展时删除。剩余额度不保存                                          |
| 自述文件     | 开启「中文自述文件」后取回的同站中文版自述文件（GitHub 渲染好的正文），在当前页显示                                                         | 不保存；本页面内最近 20 个留在内存中                                                                   |
| 剪贴板       | 点加速地址行的地址框或复制按钮，或替换原链接时点克隆地址的复制按钮，写入加速后的克隆地址；不读取                                            | 系统剪贴板                                                                                             |
| 企业版站点   | 启用的企业版站点的主机名（即授予的站点权限）                                                                                                | 浏览器保存的扩展权限                                                                                   |
| 当前页标记   | 打开弹出页时，当前页（非 GitHub 站点）头部有无 GitHub 的标记，用于识别未启用的企业版站点                                                    | 不保存                                                                                                 |
| 待授权站点   | 导入备份中尚未授权的企业版站点主机名                                                                                                        | `storage.local`，授权或取消后清除                                                                      |
| 探测结果     | 故障转移开启时各加速源站点能否连通、耗时                                                                                                    | `storage.session`，最多 5 分钟（连不上的 1 分钟）；浏览器关闭时清除                                    |
| 文件夹下载   | 下载文件夹时取回的目录列表与文件，在本地打包成 ZIP                                                                                          | 不保存；ZIP 由浏览器保存到本地                                                                         |
| 备份文件     | 导出备份时的设置、自定义词库、屏蔽规则、已启用的企业版站点；单独导出时只含该部分，「下载次数设置」单独导出时含个人访问令牌，完整备份不含    | 由浏览器保存到本地；不上传                                                                             |
| 内置词库     | 设置页「汉化设置」的「内置词库」中浏览的内置词条，取自扩展自带的词典脚本                                                                    | 不保存                                                                                                 |

## 保留与删除

- 清除浏览数据不删除扩展存储。
- 卸载扩展时，浏览器删除 `storage.local` 中的全部数据。

## 网络请求

- 停用、排除当前页、进入排除路径、改自定义词库、改时间本地化开关时，若当前页是 Turbo 缓存副本、带有 GitHub 缓存写回的译文或残留的旧译文（如扩展更新后），重新请求当前 GitHub 页面；没有 Turbo 时整页重新加载。
- GitHub 从自身缓存写回带译文的标题或页面元素时（前进后退，或帧导航到带锚点的地址），若已停止翻译，或这些译文已过时（如之后改过自定义词库、时间本地化开关，或扩展更新过），重新请求当前 GitHub 页面。
- 扩展更新、卸载或在浏览器中停用时，若页面中的旧内容脚本仍在运行（如 Chrome、Edge），且当前页是 Turbo 缓存副本或带有 GitHub 缓存写回的译文，重新请求当前 GitHub 页面。
- 以上重新请求被帧导航打断，且旧译文仍在页面上时，再请求一次。
- 点弹出页「刷新」时重新加载当前页。
- 开启加速后，单击下载链接旁的加速选项，或选了替换原链接的分类后单击 Release 附件、源码包（含 codeload）、Raw 文件、代码片段压缩包的链接时，打开加速源的地址（含原链接），由加速源代为下载。
- 开启加速后，克隆地址下方的加速地址行复制加速源的地址（含原地址）；选了替换原链接的分类时，存储库与代码片段的 HTTPS 克隆地址换成加速源的地址。用它克隆时由加速源转发；用这一远程地址推送时，Git 凭据发给加速源。
- 下载文件夹时，向当前站点请求该目录及各子目录的页面数据（JSON）与其中各文件的 Raw 地址（带 Cookie，同在页面上浏览）；选了加速分类时，文件改经该分类的加速源请求（含原地址），不带 Cookie 与来源页。文件只在本地打包成 ZIP。
- 开启「加速图片」后，头像、GitHub 静态图片、Raw 图片加载失败时，后台经加速源请求该图片（含原地址），不带 Cookie 与来源页；取到的图片只在当前页显示，不保存。
- 私有、内部存储库与私密代码片段的页面，以及带 token 的 Raw 地址，不经加速源。
- 故障转移开启时，页面上有可加速的下载链接、克隆地址，或打开「下载文件夹」按钮的菜单时，后台向各加速源站点的根路径发 HEAD 请求，探测能否连通；结果最多缓存 5 分钟（连不上的 1 分钟）。各分类用其中可用、耗时最短的。图片按耗时从短到长逐个请求，直到取到；故障转移关闭时只请求第一个支持该地址的加速源。
- 在设置页点「测速」时，向各加速源站点的根路径各发 4 次 HEAD 请求。
- 开启「自动加载」后，列表底部的分页接近视口时，向同一站点请求下一页（带 Cookie，同手动翻页），同一页面最多 30 页；「加载更多」按钮由 GitHub 自身请求。
- 图片预览中点「下载」时重新请求该图片：同站的带 Cookie，跨站的不带；取不到时在新标签页打开该图片。
- 开启「下载次数」后，github.com 上公开存储库的发行版附件出现在页面上时，由扩展后台向 GitHub REST API（`api.github.com`）请求该发行版的信息（含各附件的下载次数），不带 Cookie 与来源页；填了个人访问令牌时带上该令牌（`Authorization` 请求头）。每个发行版一次，同时只发一个，结果缓存 10 分钟；限额用尽后到重置时间之前不再请求，换了令牌后可再请求。私有、内部存储库与企业版站点不请求。
- 设置页「下载次数设置」打开时，以及令牌变动后，向 `api.github.com` 的 `/rate_limit` 请求剩余额度（不计入限额），不带 Cookie 与来源页；填了令牌时带上令牌。
- 开启「中文自述文件」后，存储库首页、目录页显示的自述文件有中文版时，向当前站点请求该文件的页面数据（JSON，带 Cookie，同在页面上浏览）；同一页面内（含站内跳转）最近取过的 20 个文件不再请求。
- 从发行版安装的 Chrome、Edge、Safari 版：打开弹出页或设置页时，距上次检查满 24 小时，向 github.com 请求本项目的最新发行版地址（HEAD，不带 Cookie 与来源页），从跳转后的地址取版本号。商店安装、企业策略部署的与 Firefox 版不请求。
- 探测、测速请求不带 Cookie 与来源页。
- 启用企业版站点后，以上对 GitHub 页面的请求同样适用于该站点。
- 不发起其他网络请求。

## 不做的事

- 不向开发者发送数据。除开启加速后交给加速源的地址外，不向任何第三方发送数据。
- 个人访问令牌只发给 `api.github.com`，不进页面中运行的脚本；只有「下载次数设置」的「导出」会把它写进备份文件。
- 备份文件只由你保存、选择；导出、导入都在本地完成。
- 加速源是第三方服务，能看到经它请求的地址与你的 IP 地址；它们如何处理这些数据，由其自行负责。
- 不出售、不转让数据，不用于广告、信用评估或与扩展功能无关的用途。
